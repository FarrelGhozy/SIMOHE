# Diagrams

Diagram pada proyek ini ditulis inline dengan **Mermaid** di dalam dokumen
terkait agar selalu sinkron dengan teks. Folder ini disediakan untuk
mengekspor/menyimpan gambar jika diperlukan.

## Cara Render
- Pratinjau Mermaid di VS Code (ekstensi Markdown Preview Mermaid) atau GitHub.
- Ekspor ke PNG/SVG bila perlu, simpan hasilnya di folder ini dengan nama yang
  sesuai (mis. `arsitektur.png`).
